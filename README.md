# SQL_Learning

Repositorio de aprendizaje de **SQL Server**: mini proyectos de bases de datos, consultas y scripts de práctica.

Cada proyecto modela un problema distinto, desde el diagrama entidad-relación hasta las consultas, para practicar diseño y SQL.

## Proyectos

| Proyecto | Descripción | Temas que practica |
|----------|-------------|--------------------|
| [Zoológico](./zoologico) | Base de datos que contiene informacion de zoologicos de todo el mundo | Normalización, JOINs, consultas, subconsultas. |
| [Centro de salud](./centro_salud) | Base de datos de un centro de salud | Normalización, JOINs, consultas, subconsultas.

## Requisitos

- SQL Server 2019 o superior
- SQL Server Management Studio (SSMS) o Azure Data Studio

## Cómo usar el repositorio

1. Clona el repositorio:
   ```bash
   git clone https://github.com/EDUARDOGR1/SQL_Learning.git
   ```
2. Entra a la carpeta del proyecto que quieras probar.
3. Lee el `README.md` del proyecto y ejecuta sus scripts en orden numérico.
